# Task board (MERN + TypeScript)

## Run
1. Server: `cd server && cp .env.example .env && npm install && npm run dev`
2. Client: `cd client && cp .env.example .env && npm install && npm run dev`
3. Open http://localhost:5173 (MongoDB must be running, or use a MongoDB Atlas URI in `server/.env`).

## API
GET/POST `/api/tasks`, PUT/DELETE `/api/tasks/:id`
